# 教室使用概況：作品集展示版

純 HTML／CSS／JavaScript，無套件、後端或建置需求。`index.html` 與 `src/` 就是可部署的靜態成品；可以直接以檔案方式開啟，或放到 GitHub Pages 的任意子目錄。

所有教室、預約、假日與場所均為**展示資料**。未修改原系統，也未提交、推送或發布。

## 原始實作與依賴追蹤

| 原始位置（相對於原專案根目錄） | 用途及匯出處理 |
| --- | --- |
| `frontend/index.html` | 原入口；`#utilization-view` 即使用概況畫面。沿用頁首、日期表單、四張指標卡、長條圖容器、計算依據、假日 details 與統計表格。移除其他管理頁籤與其內容。 |
| `frontend/src/main.js` | 沿用 DOM 渲染、格式化、使用率由高至低排序、日期提交、錯誤狀態與忙碌狀態。改用本機資料，初始日期固定為 2026-10-01～2026-10-31，首次開啟自動顯示結果。 |
| `frontend/src/styles.css` | 複製第一個完整樣式區塊，包含使用概況所有規則及 850px／520px 響應式斷點；不攜帶其他頁面樣式。 |
| `frontend/src/api.js` | 原本提供 `fetchUtilization` 的遠端查詢與回應驗證。展示版以 `src/mock-data.js` 的同名本機函式替代，沒有複製 API 模組。 |
| `frontend/src/instructors.js`、`frontend/src/events.js` | 原 main 的其他畫面副作用匯入；展示版已移除，不需追蹤其管理、課表與儲存相依鏈。 |
| `frontend/src/navigation.js` | 原管理畫面的 `?view=utilization` 導覽狀態；此畫面沒有獨立框架路由。展示版僅有單頁入口，不需導覽模組。 |
| `backend/app/services/utilization_service.py` | 只參考計算規則：雙端包含、每日三段共 10 小時、假日關閉、預約裁切及重疊合併。未複製 Python、資料庫或真實行事曆。 |

圖表使用原本的 `.bar-row`／`.bar-track`／`.bar-fill` DOM 與 CSS，沒有圖表套件。`▦`、`→`、`↗` 是文字字元，不需圖示庫。原畫面沒有必要的圖片或字型檔；字型順序保留 `Inter, "Noto Sans TC", "Microsoft JhengHei", sans-serif`，由訪客裝置提供，不向外部字型服務請求。不同裝置可因字型可用性產生差異。

## 匯出內容

```text
index.html           可部署入口、原版面結構
src/styles.css       原畫面的共用與響應式樣式
src/main.js          沿用的渲染與互動
src/mock-data.js     虛構資料產生及統計計算
tools/export.py      從本專案重新擷取畫面的工具（非執行依賴）
tools/verify.cjs     計算、渲染及資源檢查（非執行依賴）
README.md            整合與驗證說明
```

使用一般 defer script，依序載入本機資料函式與畫面程式，無 ES module 載入限制，因此也可用 `file://` 開啟。所有執行資源都使用 `./src/...` 相對路徑。沒有 npm 依賴、CDN、登入、資料庫、Cookie、瀏覽器儲存或網路資料請求。

## 啟動、預覽、建置

1. 直接開啟此目錄的 `index.html`。
2. 若需 HTTP 預覽，在**原專案根目錄**執行：

   ```powershell
   python -m http.server 8765 --bind 127.0.0.1
   ```

   開啟本機連接埠 8765 下的 `/portfolio-export/classroom-usage/`。此路徑也可驗證子目錄載入。
3. 不需建置，`index.html` 加 `src/` 就是最終成品。
4. 可選檢查（需 Node.js 18 以上），在展示目錄執行：

   ```powershell
   node tools/verify.cjs
   ```

`python tools/export.py` 只適用於仍保留原專案目錄結構時；會重新產生 `index.html`、`src/styles.css`、`src/main.js`，覆寫對這三個檔案的手動變更。一般整合或部署不需執行。

## 整合到既有靜態作品集

將 `index.html` 與完整 `src/` 複製到作品集的 `demos/classroom-usage/` 等子目錄，再從作品集連結到 `./demos/classroom-usage/`。GitHub Pages 的儲存庫名稱前綴不影響此頁資源載入，不需設定 base URL 或路由轉址。

若要嵌入既有頁面，可用 iframe 指向該目錄，設定適當寬高與 `title="教室使用概況展示"`。原 CSS 含 `body`、`main`、`table` 等全域選擇器，建議以獨立頁或 iframe 保留原樣式，避免直接混入作品集全域 CSS。

## 模擬資料與互動

- 場所為虛構「森光學苑」，包含 16 間虛構教室，其中一間固定沒有預約，仍納入容量。
- 本機依日期與教室編號產生固定預約；同一日期的數據不因查詢區間改變。跨午休、傍晚休息及重疊預約會經裁切、合併後計算；有效預約次數計入有占用開放時段的預約。
- 每月 10 日是虛構休館日、24 日是虛構維護日，**不是實際國定假日**。其餘日期含週末開放。原本的排除空間說明保留，資料產生器只建立納入統計的教室。
- 可查詢 2000～2100 年，單次最多 366 天，包含開始與結束日。全為假日的區間會顯示零占用與零容量，使用率顯示「不適用」。
- 容量 = 開放日數 × 10 小時 × 教室數；總占用 = 各教室合併後占用加總；總使用率 = 總占用 ÷ 總容量。百分比只在顯示時四捨五入到兩位小數。
- 保留原生日期輸入、提交、圖表與表格自動降冪排序、圖表垂直捲動、表格橫向捲動、假日展開與清單捲動。原畫面沒有手動排序按鈕，展示版沿用自動排序。
- 可在 `src/mock-data.js` 調整教室、每日預約規則與模擬假日；修改初始日期請調整 `src/main.js`。
- 移除真實地點、遠端 API、後端快照及更新時間訊息，沒有攜帶環境設定、密鑰、Token、真實預約或個資。

## 驗證結果與限制

已通過 JavaScript 檢查程式：多種日期區間、閏年、重疊合併、無預約教室、全假日、日期錯誤與過長區間、指標加總一致性、原渲染器執行、日期再次提交、圖表排序、16 筆表格及假日清單渲染、相對資源存在性、無 API／外部 URL／網路呼叫，以及兩個原響應式斷點存在。

本次透過可用的 Node 執行環境與最小 DOM 測試替身執行 `tools/verify.cjs`，結果 PASS；測試替身不代表真正瀏覽器。執行資源只有三個本機檔案，已確認必要資源存在。

本次瀏覽器工具未提供可用瀏覽器，因此尚未實際驗證桌面／手機排版、日期選擇器、原生 details 展開、捲動與 Network 面板。建議發布作品集前以桌面寬度與 390px 手機寬度確認上述呈現。沒有產生瀏覽器截圖或聲稱完成視覺驗證。
