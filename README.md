# pheeb.github.io

## 教室管理互動展示

- 獨立展示目錄：`portfolio-export/classroom-usage/`，完整保留匯出的 `index.html`、`src/`、`tools/` 與說明文件。
- 本機直接開啟 `portfolio-export/classroom-usage/index.html`；部署後可透過相同子路徑存取，或從教室管理介紹頁的「開啟互動展示」進入。
- 展示使用虛構資料，不需後端、資料庫或建置；樣式與程式只在展示頁載入。
- `tools/export.py` 依賴原教室管理專案的目錄結構，請勿在此作品集執行。驗證可在展示目錄執行 `node tools/verify.cjs`。
