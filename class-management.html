01 / OVERVIEW

專案概況

背景與問題
公司培訓業務需要同時管理班別課綱、各期班級、實際開設課程與學生名單，但 Moodle 原有的課程與分類架構，無法直接完整對應公司的管理流程。教務與導師需要在不同頁面處理課程、人員及教材設定，同一班別重複開班時，也容易產生重複建置、資料對應與權限維護的負擔。因此，本專案以 Moodle 為基礎，建立符合業務需求的班別與班級課程管理功能，整合資料匯入、教材共用及角色權限，讓培訓管理流程更集中且一致。
使用對象與目標
主要使用者為教務人員、導師、授課教師與學生。教務人員可集中維護班別課綱、各期班級、開課資訊及學生名單；導師與教師可在授權範圍內管理班級、教材與學生，並查看學習進度及成績；學生則可透過「我的班級」與「我的課程」快速找到學習內容。專案目標是減少重複輸入與跨頁查找，清楚區分共用課綱與各班實際授課內容，並讓不同角色取得符合職務需求的操作權限。
我的貢獻
我負責將公司的培訓管理需求轉換為 Moodle 客製功能，設計並開發「班別、班別課程、班級、班級課程」四層資料架構及管理介面。實作內容包含 Excel／CSV 批次匯入、依班級代號判斷所屬班別、班級查詢、課程排序與發布，以及學生名單匯入與選課整合；同時開發共用教材範本、版本發布與班級教材匯入功能，支援依學生、群組及時間設定觀看權限。此外，我也調整導師與教務的角色權限、導覽入口及操作流程，並處理 Moodle 升級、外掛相容性與開發環境問題。

02 / FEATURES

功能與畫面

核心功能一｜AI 學習小幫手

學生可透過對話介面提出課程疑問、整理複習重點及釐清作業準備方向，並延伸搜尋相關教學影片。以下展示使用虛構的「網頁入門」課程與預設模擬回覆，未連接即時 AI 或實際班級資料。

關鍵操作
輸入問題後按 Enter 或送出按鈕，使用 Shift + Enter 換行。等待期間顯示三點動畫並暫停送出，回覆完成後可繼續提問。「搜尋相關教學影片」會以輸入框內容或上一則問題開啟 YouTube 外部搜尋。
資訊層級
上方以標題與展示提示說明用途，中段以左右對齊及不同底色區分學生問題與助理回覆，下方集中輸入框、送出按鈕與鍵盤提示；影片搜尋作為延伸學習入口，放在主要提問操作之後。
設計考量
以單一對話入口減少查找負擔，透過空白檢查、2000 字元上限及等待時鎖定輸入避免無效或重複送出；中文組字期間不觸發送出。回覆採純文字呈現，訊息區可捲動，並提供新訊息朗讀提示及減少動畫偏好支援。

核心功能二｜班級、課程與人員整合管理

整合班別、各期班級、班級課程與學生名單，讓管理人員從班別逐層進入班級，完成開課資料維護、講師安排及學生匯入。以下以管理員角色展示完整流程，所有班級、課程與人員均使用虛構資料。

關鍵操作
依班級代號、教務或導師搜尋並切換分頁，透過列內新增或 CSV 匯入建立班級與課程草稿；在班級課程調整時數、選擇講師，自動儲存後可拖曳排序，或點選移動圖示指定位置。發布前可確認或取消，學生名單則可下載範例後匯入並檢查結果。
資訊層級
以「班別 → 班級 → 班級課程」呈現共用課綱與各期開課的關係；班級列表集中顯示代號、期間、地點與負責人，課程列表再呈現時數、講師及發布狀態。「我的班級」與「我的學生」採左右欄工作區，先選班級，再查看所屬課程或名單。
設計考量
用搜尋、分頁及列內操作減少跨頁維護，並以儲存狀態與通知回饋操作結果。匯入先驗證整批資料，遇到重複或衝突時不留下部分異動；發布前檢查講師、時數與資料關聯，並要求確認。排序同時提供拖曳與位置選擇，方便鍵盤及觸控操作。

核心功能三｜教材共用、版本發布與觀看權限管理

管理人員可將共用範本發布為具名版本，選取教材加入各班課程，再逐份設定觀看對象與開放時間，兼顧教材共用及各班授課安排。以下使用虛構班級、學生與教材，展示發布、匯入及觀看設定的操作流程。

關鍵操作
範本開放可以限定角色及範圍。
資訊層級
依「共用範本 → 發布版本 → 班級教材 → 單份教材設定」逐層展開。
設計考量
減少教師在不同班級重複上傳教材的時間。

03 / TIMELINE

開發時程

  1. 需求

    建置以 Moodle 為基礎的教學管理平台，整合班級、課程、人員與教材管理，並提供角色權限控管及 AI 學習輔助。

  2. 設計

    採用 Moodle 外掛模組化架構，區分班別、班級與開課資料，搭配教材版本發布及存取權限機制，支援跨班教材共用。

  3. 開發

    使用 PHP 與 Moodle API 實作管理功能，搭配 JavaScript 完成互動介面與 AI 服務串接。

  4. 測試

    自訂外掛有測試程式。
