03 / PROJECT · 資料處理工具

題庫整理與重複檢查工具

將 PDF 題庫轉換為結構化 CSV，透過完全重複與文字相似度比對，協助整理題目並找出需要人工複核的內容。

專案類型
題庫資料整理與檢查
操作方式
命令列工具輸入 PDF 或 CSV，輸出題庫檔案與終端機比對報告。
使用技術
  1. pypdf：擷取 PDF 文字
  2. pandas：讀取與清理 CSV 資料
  3. jieba：中文斷詞
  4. scikit-learn：TF-IDF 向量化與餘弦相似度
  5. hashlib：MD5 完全重複比對
使用語言與格式
  1. Python：資料解析與比對流程
  2. 正規表示式：題目欄位擷取
  3. CSV：結構化題庫與交換格式

01 / OVERVIEW

專案概況

背景與問題
PDF 題庫中的題幹、選項、答案與分類分散在文字段落中，逐題整理及人工檢查重複內容需要反覆查找。當題目數量增加，也容易遺漏僅有部分文字差異的相似題目。
使用對象與目標
協助題庫整理與審查人員，先將符合指定格式的文字型 PDF 轉成 CSV，再找出完全重複與高度相似的題目，縮小人工複核範圍。
實作內容
以兩支 Python 程式串接資料整理與檢查流程：pdf_to_csv.py 負責擷取 PDF 文字並解析題目欄位；find_duplicates.py 負責清理題幹、計算 MD5 與 TF-IDF 餘弦相似度，並在終端機列出比對結果。

02 / FEATURES

功能與流程

核心功能一｜PDF 題庫轉換

使用 pypdf 擷取文字，以評鑑主題標記切分題目，透過正規表示式整理分類、評鑑內容、題幹、四個選項、答案與難易度。輸出採 UTF-8 BOM 編碼的 CSV，方便接續整理與比對。

操作方式
python pdf_to_csv.py input.pdf questions.csv
適用範圍
目前依固定欄位標記解析文字型 PDF；掃描影像與不同排版的題庫需另行處理，轉換後仍需檢查欄位是否完整。

核心功能二｜完全重複題目檢查

讀取 CSV 的 question 欄位，排除缺值並清理題幹。比對前移除空白、統一英文大小寫，再計算 MD5，找出正規化後內容相同的題目。

設計考量
先用明確的文字規則找出完全重複，再將文字相近的題目交由相似度流程檢查；目前比對依據為題幹，不包含選項與答案。

核心功能三｜文字相似度比對

透過 jieba 中文斷詞與 TF-IDF 建立題幹向量，計算兩兩題目的餘弦相似度。預設列出相似度達 85% 且非完全相同的題目配對，顯示題幹與分數供人工複核。

操作方式
python find_duplicates.py questions.csv
結果解讀
分數反映詞彙與文字組成的相近程度，仍需人工判斷題意、答案及保留方式。程式只列出報告，不會自動刪除題目。

03 / WORKFLOW

實作流程

  1. 整理格式

    確認 PDF 題目標記，定義題幹、選項、答案與分類等 CSV 欄位。

  2. 解析資料

    擷取 PDF 文字，切分題目並輸出結構化題庫。

  3. 分層比對

    先以 MD5 檢查完全重複，再透過 TF-IDF 與餘弦相似度篩選相似題目。

  4. 人工複核

    依報告檢視題幹、選項與答案，確認是否為重複題或需要保留的變化題。

04 / RESULT

成果

完成成果
建立從 PDF 轉換、CSV 清理到重複題目檢查的命令列處理流程，將完全重複與高度相似的題目分別列出，提供題庫整理與人工審查的依據。
後續方向
可延伸支援更多 PDF 格式、選項與答案比對，以及報告檔案匯出。大量題庫的兩兩相似度計算，也可進一步評估分批處理方式。
